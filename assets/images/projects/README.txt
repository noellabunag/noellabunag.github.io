PROJECT SCREENSHOTS GO HERE
===========================
Save real screenshots of your charts, dashboards, diagrams and code here,
then reference them from the case study pages in /projects.
Tips: PNG for charts and dashboards, about 1600px wide, under ~400 KB each.
Use lowercase names with hyphens, e.g.  powerbi-dashboard-1.png
See the main README.md > "Replacing project images" for the exact steps.
